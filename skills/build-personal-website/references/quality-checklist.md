# 个人网站交付检查清单

## 内容

- [ ] 姓名、定位、经历、项目和联系方式准确。
- [ ] 没有未标记的占位内容。
- [ ] 每个项目清楚说明问题、职责、过程和结果。
- [ ] 主要行动按钮明确且有效。
- [ ] 演示功能被明确说明为演示。

## 布局与视觉

- [ ] 手机、平板和桌面端主要内容完整可读。
- [ ] 页面没有横向溢出、遮挡或意外跳动。
- [ ] 字号、行高、对比度和点击区域合理。
- [ ] 标题、正文、辅助信息和操作层级一致。
- [ ] 图片裁切和比例符合内容意图。

## 交互与无障碍

- [ ] 导航、链接、按钮、弹窗和表单可以使用。
- [ ] 主要操作可通过键盘完成。
- [ ] 键盘焦点清晰，弹窗打开和关闭行为合理。
- [ ] 图片具有合适的替代文本。
- [ ] 页面结构使用合理的语义标签。
- [ ] `prefers-reduced-motion` 下内容仍完整可用。

## 性能与媒体

- [ ] 首屏关键内容优先加载。
- [ ] 非首屏大型模块按需加载。
- [ ] 图片包含尺寸并采用适合网页的格式。
- [ ] 视频包含封面和必要的降级方案。
- [ ] 没有明显重复下载或不必要的大型依赖。
- [ ] 页面加载过程中没有严重布局跳动。

## 构建与部署

- [ ] 安装、测试和构建命令成功。
- [ ] 浏览器控制台没有明显错误。
- [ ] 页面刷新和直接访问主要地址正常。
- [ ] 图片、视频、字体和脚本路径正确。
- [ ] 子路径部署时公共资源仍可访问。
- [ ] 线上页面与本地验证结果一致。

## 交付说明

- [ ] 说明完成内容和主要设计判断。
- [ ] 说明运行、构建和部署方式。
- [ ] 列出执行过的验证。
- [ ] 列出剩余占位内容和已知限制。
