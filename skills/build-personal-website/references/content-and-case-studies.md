# 内容与案例模板

## 个人网站简报

在开始设计前整理：

- 姓名或品牌名称：
- 一句话定位：
- 目标访客：
- 网站目标：
- 主要行动按钮：
- 希望留下的印象：
- 不希望采用的风格：
- 现有素材：
- 技术或部署限制：

无法确认的事实保留为空或标记为占位内容，不要自行补造。

## 首页内容

### 首屏

- 我是谁：
- 我主要做什么：
- 我的特点或价值：
- 主要行动：
- 次要行动：

### 关于

- 简短背景：
- 当前关注方向：
- 工作方式：
- 能够提供的价值：

### 能力或服务

每项能力至少关联一个项目、成果或具体行为作为证据。

## 项目案例

为每个代表项目整理：

- 项目名称：
- 时间与背景：
- 面向的用户或场景：
- 需要解决的问题：
- 我的职责：
- 约束条件：
- 采用的过程：
- 关键判断：
- 最终结果：
- 可以公开的素材：
- 尚未验证或不能公开的内容：

优先讲清楚问题、判断和结果，不把工具列表当作案例主体。

## 内容检查

- 首屏能否在短时间内说明网站主人是谁和做什么。
- 项目能否证明页面中声称的能力。
- 每个区块是否承担清晰且不同的任务。
- 是否存在重复、空泛或没有证据的表达。
- 是否误把团队成果全部描述成个人成果。
- 所有事实、数据和联系方式是否得到用户确认。
